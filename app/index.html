Verbindung beitreten

Du nutzt die App vom Home-Bildschirm? Links öffnen auf dem iPhone leider immer Safari, und Safari hat einen eigenen Speicher. So kommt der Code in die App:

  1. Hier auf Code kopieren tippen.
  2. Die App vom Home-Bildschirm öffnen.
  3. Dort Menü → Verbindungen → Code eingeben → Einfügen → Verbinden.

Standort teilen

Wie lange?

Gesendet wird nur, solange die App offen ist: beim Fahren alle 30 Sekunden, im Stand alle 5 Minuten. Ohne Netz sehen die anderen deinen letzten Standort mit Uhrzeit, die Strecke dazwischen kommt nach. Verschlüsselt – nur wer den Code hat, sieht dich.

Wer ist zu sehen?

Google-Listen übernehmen

Wähle, welche Listen in die App kommen. Den Namen kannst du ändern – gleiche Namen werden zu einer Liste zusammengelegt, doppelte Orte nur einmal übernommen. Kategorie und Land ordnet die App danach selbst zu (braucht Internet).

Gebiet hinzufügen

Aktueller Kartenausschnitt Lädt genau das, was du gerade auf der Karte siehst. Gut für ein Gebirge, eine Strecke oder Grenzregionen.
